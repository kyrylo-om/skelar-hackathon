## Untested assumptions and gaps

All runtime security, migration and concurrency assertions are **Not verified** here. Tests demonstrate intended behavior only; injection text currently never reaches a model. Refund eligibility/execution, provider timeouts, actor/critic retries, policy knowledge, customer/operator UI, signup/provisioning, pagination, metrics, automatic renewal and production deployment configuration are absent or incomplete.

Action replay returns the current subscription, while `Action.result.subscription` is a success-time snapshot. Handoff does not revoke already persisted successes; replay may return that read-only result after the conversation leaves AI. A new customer message on a resolved case conflicts, but a completed duplicate can return cached response with current resolved status. These follow the ordering in `begin_turn` and `_execute`, not separate promises of a reopened conversation.
